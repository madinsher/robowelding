# Шрифты

Шрифты, которыми нарисованы подписи, таблички и маркировка этапа 1 и этапа 2. Лежат в репозитории, чтобы сцена и
титры выглядели одинаково на любой ОС (на Windows нет DejaVu / FreeSans по умолчанию).

| Файл | Семейство | Лицензия |
|---|---|---|
| `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` | DejaVu Sans 2.37 | свободная лицензия Bitstream Vera / DejaVu (см. `LICENSE-DejaVu.txt`), распространение разрешено |
| `FreeSansBoldOblique.ttf` | GNU FreeFont (FreeSans) | GNU GPL v3+ с исключением для шрифтов (font embedding exception), https://www.gnu.org/software/freefont/license.html |
