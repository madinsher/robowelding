# robowelding

Материалы по роботизации сварки трубных узлов.

* `demo_video/` — генератор демонстрационного видео роботизированной ячейки сварки трубных спулов
  (Blender/EEVEE, полностью процедурная сцена: ABB IRB 4600 на треке, двухосевой позиционер, спул
  DN250, хореография двух кольцевых швов, эффекты дуги, титры и звук) и скрипт для воспроизведения
  той же ячейки в RoboDK. См. `demo_video/README.md`.
* `stage2_logistics/` — этап 2: подача заготовок, обработка и выдача готового изделия. Пока только план работ (`stage2_logistics/PLAN.md`); подпроект импортирует инструменты этапа 1 через `stage2_logistics/tools.py`.
