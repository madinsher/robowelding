# robowelding

Материалы по роботизации сварки трубных узлов.

* `demo_video/` — генератор демонстрационного видео роботизированной ячейки сварки трубных спулов
  (Blender/EEVEE, полностью процедурная сцена: ABB IRB 4600 на треке, двухосевой позиционер, спул
  DN250, хореография двух кольцевых швов, эффекты дуги, титры и звук) и скрипт для воспроизведения
  той же ячейки в RoboDK. См. `demo_video/README.md`.
* `stage2_logistics/` — этап 2: полный цикл участка (кассета комплекта → сборочно-прихваточный стенд →
  робот-погрузчик на треке → сварочная ячейка этапа 1 → выходной рольганг → маркировка и контроль шва → стеллаж
  и AGV). Процедурная сцена Blender с хореографией всех машин, две версии ролика
  (`ru` ПИГРУПП / `en` ATOMIX) и их промежуточные склейки в `stage2_logistics/deliverables/`, станция RoboDK.
  Рендер одной командой — `stage2_logistics/RENDER.md`, описание — `stage2_logistics/README.md`; подпроект
  импортирует инструменты этапа 1 через `stage2_logistics/tools.py`.
