# Демо-видео: роботизированная ячейка сварки трубных спулов

Генератор демонстрационного видео (в стиле walkthrough-роликов RoboDK, но с фотореалистичным
рендером Blender/EEVEE) для предложения по роботизации сварки трубных узлов
(«Решение 4 — гибкая ячейка сложных спулов»: робот на линейном треке + двухосевой позиционер).

Сцена строится полностью программно (Python + `bpy`, Blender 4.5 LTS как модуль):

* **Изделие** — спул DN250: приварной фланец (WN) + отвод 90° 1.5D + прямая труба,
  два кольцевых стыка (A: фланец–отвод, B: отвод–труба), разделка кромок, растущие
  сварные швы (прогресс шва управляется шейдером по углу вокруг оси стыка).
* **Позиционер** — двухосевой (наклон/вращение) с U-образной люлькой и планшайбой.
* **Робот** — ABB IRB 4600-40/2.55 (меши и кинематика из URDF пакета `compas_fab`),
  на линейном треке (7-я ось), сварочная горелка MIG с изгибом 45°, лазерный датчик стыка,
  шланг-пакет и подающий механизм на плече.
* **Хореография** (`cell/animation.py`): поиск стыка лазером → шов A вращением изделия при
  неподвижной горелке (колебания) → индексация позиционера → шов B секторами 90° роботом
  с поворотом изделия на 180° → возврат в позицию загрузки. IK — численный (DLS, 5 DoF со
  свободным вращением вокруг оси горелки), траектория кэшируется в `out/anim_cache_*.npz`.
* **Окружение** (`cell/environment.py`) — цех по фото участка: колонны, кран-балка, ограждение
  с дверью и световой завесой, шкаф контроллера, источник, бочка с проволокой, станция очистки
  горелки, вытяжной зонт, паллеты с деталями и готовыми спулами.
* **Эффекты дуги** (`cell/vfx.py`) — свет дуги с мерцанием, ядро/ореол, искры (частицы),
  дым (объём), лазерная линия датчика, bloom и виньетка в композиторе.
* **Пост-обработка** (`post/`) — титры и подписи на русском (PIL + ffmpeg), синтезированный звук
  (фон цеха, сервоприводы, треск дуги), сборка итогового MP4. Подписи — в `post/storyboard.json`.
* **RoboDK** (`robodk/`) — скрипт `build_station.py`, воспроизводящий ту же ячейку и хореографию
  в RoboDK (робот из библиотеки, трек, 2-осевой позиционер как механизмы, спул из `spool.stl`,
  кривые швов, программы MoveL, виды камер). Подробности в `robodk/README.md`.

## Запуск

```bash
cd demo_video
python3 build.py --still 300 --res 960 540 --engine CYCLES   # кадр без xvfb (Cycles)
xvfb-run -a python3 build.py --still 300 --res 1280 720        # кадр EEVEE
xvfb-run -a python3 build.py --preview                          # каждый 8-й кадр, 640x360
xvfb-run -a python3 build.py --render                           # полный рендер 1920x1080 в out/frames/
python3 post/compose.py --frames out/frames --out out/demo_final.mp4   # титры + звук
python3 build.py --export-stl robodk/spool.stl                  # геометрия спула для RoboDK
```

Зависимости: `pip3 install bpy==4.5.* numpy pillow`, `ffmpeg`, `xvfb` (для EEVEE без GPU).

Компоновка ячейки задаётся в `cell/layout.py` (единый источник констант), раскадровка и
подписи — в `post/storyboard.json`.
